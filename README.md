#  CampusFind

CampusFind is a web-based Lost and Found Management System developed for **Dr. TMA Pai Polytechnic**. The platform provides a simple way for students to report lost or found items, browse listings, and help reunite belongings with their owners.

## Features

- User Registration and Login
- Report Lost Items
- Report Found Items
- Browse Lost & Found Listings
- Admin Panel for Managing Reports
- MySQL Database Integration

## Tech Stack

- HTML5
- CSS3
- PHP
- MySQL
